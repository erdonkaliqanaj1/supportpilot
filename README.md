# SupportPilot

SupportPilot is an AI-powered customer support ticketing and management system. It leverages Large Language Models (LLMs) to automatically categorize incoming support tickets, draft intelligent response suggestions for agents, and streamline resolution workflows.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **AI / LLM Integration:** OpenAI API / LangChain for automated ticket triage and response generation
